Migrating from predictmeans 1.x

predictmeans 2.0 removes options that did the same thing under two names, the printing and plot settings in the calls of the analysis functions, five functions, and the 1.x smooth interface (smZ(), smoothZ). The means functions share one vocabulary: conf_level, df_method, at, weights, vcov, plot.

To update a 1.1.1 script, run it. A removed argument or function stops with its 2.0 spelling, the value you gave filled in:

library(predictmeans)
Oats <- as.data.frame(nlme::Oats)
Oats$nitro <- factor(Oats$nitro)
fm <- lmer(yield ~ nitro * Variety + (1 | Block/Variety), data = Oats)
try(predictmeans(fm, "nitro", level = 0.1, Df = 30))
#> Error : predictmeans(): 'level' was removed in predictmeans 2.0: use conf_level = 0.9.
#>   'Df' was removed in predictmeans 2.0: use df_method = 30.
#> See vignette("migrating") for every change from 1.1.1.

Nothing is silently ignored. A rewritten call gives the same numbers as 1.1.1, apart from the changes listed under Defaults that change and Results that change. The package sources check this for every rewrite (dev/snapshot-*.R, dev/check-smz-migration.R).

Notes:

  • bs = "os" is the O’Sullivan spline of smZ() (k interior knots, 6 by default as smZ()); bs = "ztps" is its thin-plate basis (k = 6 knots per axis as smZ(); the default of bs = "ztps" is 10).
  • Knots of your own (the last pair above): here the fits differ, and 2.0 is right: 1.x centred x before smZ() saw it (ncenter = TRUE, the default), so knots given in the units of the data were in the wrong place (in the check: REML log-likelihood -398.53 against -389.12; 1.x with ncenter = FALSE gives -389.12).
  • The Poisson fit through lme4 agrees to the optimizer’s tolerance (log-likelihood within 1e-6, fitted counts within 0.003); through glmmTMB to 1e-6.
  • smZ(x, drv = 1) (the derivative of the basis) is semipred(fit, ..., deriv = 1).
  • Any other basis: s(x, bs = "user", xt = list(basis = f)), with f(x) returning the basis matrix; its columns must not be in the span of the constant and x (the fixed part). The other smZ() types ("bs", "ns", the splines2 types, "smspline") gave their B-spline or natural-spline columns iid random coefficients, which shrinks the curve towards zero rather than towards a straight line; they have no formula form that gives the same fit. bs = "os" is the penalised B-spline that does the same job properly.
  • fit$knots_lst, fit$range_lst, fit$type_lst and fit$smoothZ_call are no longer in the result; a fit made with smZ() and saved before 2.0 cannot be used by semipred() (it says so): refit it.

In the two models with a curve per group, the 1.1.1 formulas had the factor but not its interaction with the covariate. A smooth by a factor then has no unpenalised slope per group, so the groups’ straight-line trends are shrunk towards each other. The formula form adds the slopes itself, which is why the 2.0 fits are better.

Results that change

Kenward–Roger adjusted standard errors

For lmer models fitted by REML, standard errors, confidence limits, LSDs and p-values use the Kenward–Roger adjusted covariance, as SAS DDFM=KR and emmeans do; 1.x used the unadjusted covariance with Kenward–Roger df. For balanced designs the two agree; for unbalanced ones the adjusted SEs are slightly larger. vcov_adjust = FALSE gives the 1.x numbers:

Om <- Oats[-c(1, 2, 30), ]   # unbalanced
fm_u <- lmer(yield ~ nitro * Variety + (1 | Block/Variety), data = Om)
new <- predictmeans(fm_u, "Variety")
old <- predictmeans(fm_u, "Variety", vcov_adjust = FALSE)
cbind(SE_2.0 = new$means$std.error, SE_1.x = old$means$std.error)
#>        SE_2.0   SE_1.x
#> [1,] 8.086340 8.085432
#> [2,] 8.057580 8.057580
#> [3,] 8.138192 8.132226

Means that cannot be estimated are NA

A mean that depends on aliased coefficients used to be a number that depended on which coefficient R dropped. It is now NA, with a message; estimable pairwise differences are still shown. Means over empty cells keep the 1.x rule: the average of the observed cells, with a warning.

Permutation tests

  • permmodels() uses Freedman–Lane permutations (method = "auto"): each term, coefficient or pair is tested against the model without it, so the other terms keep their effects. It works for glm, glmer and glmmTMB too, without refits. method = "raw" is the 1.x scheme.
  • Mixed-model residuals are decorrelated with the symmetric square root of their covariance; the Cholesky factor of 1.x gave results that depended on the order of the data. So method = "raw" p-values for mixed models also differ slightly from 1.x.
  • permanova.lmer() refitted each model with and without the term through permlmer(); permmodels() tests the same hypotheses, with other permutation p-values.

Other changes in numbers

  • trans = function(x) exp(x) - 1: the pairs have no ratio columns. With an offset, 1.x gave ratios of y + 1 labelled as ratios of y.
  • semireg(ngbinomial = TRUE) took theta from a Poisson fit, which is not the maximum-likelihood fit (on a test data set log-likelihood -1133.60 against -1132.98 for semireg_tmb(family = glmmTMB::nbinom2); theta 3.31 against 2.80, true value 3).
  • Smooth models with knots given in the data’s units, or whose 1.x formula left out the slope of each group: see the table above.

Bugs fixed

Some 1.x results were wrong and are now right: permlist with atvar, a user-supplied Df for lmer models, factor levels containing ":", several Kmatrix() cases with transformed covariates, and others listed in NEWS.md.

New in 2.0

  • Degrees of freedom: df_method = "Kenward-Roger", "Satterthwaite", "containment", "between-within", "inner-outer", or a number.
  • Averaging weights: weights = "proportional" (SAS OM), "outer", "cells", "flat".
  • Comparisons: adj = "sidak", "scheffe", "mvt" (exact single-step); contrast_family(), specify_contrast(), pm_joint(), pm_slopes(); comparison intervals and letter_ci. See vignette("contrasts").
  • Response scale: back-transformation detected from the formula or the link, delta-method SEs, ratios and odds ratios.
  • Smooth models: smooths in the formula (s(), t2(), by =), semipred() with simultaneous bands, derivatives and curve differences, anova() of smooth terms.
  • Resampling: Freedman–Lane permutations for GLMs and GLMMs, restricted permutations (permindex()), bootmodels(). See vignette("resampling").
  • Checks: pm_check(), residplot() and CookD() for every model class, varcomp() with intervals and tests, R2_model().
  • Other model classes with a few methods (?pm_coef); fewer dependencies; faster Kenward–Roger and Satterthwaite.
